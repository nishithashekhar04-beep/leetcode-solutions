## Problem: Reverse a String (Easy)

**Link:** https://leetcode.com/problems/reverse-string/

### Approach

I used two pointers to reverse the string. One pointer starts from the beginning and the other starts from the end, and the characters are swapped until they meet.

### Complexity

- Time: O(n)
- Space: O(1)

### Notes

The program was tested locally with different test cases, including a normal string and an edge case with a single character.
