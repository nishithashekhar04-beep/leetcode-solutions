## Problem: Valid Anagram (Easy)

**Link:** https://leetcode.com/problems/valid-anagram/

### Approach

I used a character-counting method to compare the two strings. The frequency of each character is counted in both strings, and if the counts are the same, the strings are anagrams.

### Complexity

- Time: O(n)
- Space: O(1)

### Notes

The program was tested locally with different test cases, including an anagram pair and a pair of strings that are not anagrams.
